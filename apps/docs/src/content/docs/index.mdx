Formly Editor is an MIT-licensed project providing an editor framework for ngx-formly in Angular.
Its editor libraries are internal source modules, not published npm packages.

Formly Studio is the project's demo application. Use this browser-local demo to build and preview
forms, then export their `FormlyFieldConfig[]` for an Angular application. These guides cover the
demo, configuring a local checkout for your own components, and consuming exported forms.

[Open Studio demo](https://formlystudio.com/) or visit the
[source repository](https://github.com/sesan07/formly-editor).
