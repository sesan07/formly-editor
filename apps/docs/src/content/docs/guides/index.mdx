title: Using the Studio Demo
description: Task-focused guides for building and managing forms in the Formly Editor project's Studio demo.
---

Formly Studio is the demo application for Formly Editor. These guides describe the demo's workflows.

Build a first form with the [quickstart](/guides/form-editor-quickstart/), then use the guide for the
task at hand.

## Create and edit

- [Start a form](/guides/templates/): choose a blank form or starter template.
- [Add and configure fields](/guides/add-and-configure-fields/): set keys, labels, choices, validation,
  and presets.
- [Structure fields](/guides/organizing-fields/): arrange groups and repeating sections.
- [Layout and styling](/guides/form-layout-and-styling/): control spacing and responsive layout.
- [Preview and test](/guides/previewing-and-testing/): test validation and model values.

## Manage and share

- [Manage your workspace](/guides/manage-your-workspace/): organize form documents and folders.
- [Save, import, and export](/guides/save-import-and-export/): protect local work and move forms.
- [Inspect form JSON](/guides/working-with-json/): review the generated configuration.
- [Troubleshooting](/guides/empty-states-and-recovery/): resolve empty panels and common recovery
  states.

Application developers can continue with [Use an exported form](/developers/use-an-exported-form/).
